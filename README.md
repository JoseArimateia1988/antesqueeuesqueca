# Antes que eu esqueça — Home

Versão estática e responsiva da nova home editorial.

## Arquivos

- `index.html`
- `styles.css`
- `script.js`

## Como publicar no GitHub Pages

1. Extraia o ZIP.
2. Envie os três arquivos para a raiz do repositório.
3. Substitua os arquivos antigos quando o GitHub perguntar.
4. Aguarde cerca de 1 minuto e atualize o site.

## Observação importante

Os links internos das gavetas ainda apontam para `#`, porque as páginas individuais serão criadas na próxima etapa.
O primeiro guardado já aparece como conteúdo real na home, mas a página completa dele ainda será construída separadamente.
