ANTES QUE EU ESQUEÇA — protótipo navegável

Abra index.html no navegador.

Páginas:
- index.html: home
- artigo.html: página de leitura
- gaveta.html: página por assunto
- busca.html: busca
- sobre.html: manifesto, sobre e arquivo

Para editar textos e publicações:
- abra data.js
- duplique um objeto dentro da lista POSTS
- altere título, slug, data, tags, corpo e links

Fluxo editorial novo (em teste):
- abra painel/index.html
- avance por Radar, Pesquisa, Arquitetura, Escrita, Imagens, Prévia e QA
- exporte o JSON do projeto
- siga docs/EDITORIAL_WORKFLOW.md para gerar a edição em uma branch
